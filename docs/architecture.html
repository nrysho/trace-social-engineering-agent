A stalled branch pivots to the next approach on the fixed ranked list; branch lessons are not yet carried forward. Unknown delivery → stop and reconcile the original request.

Persistence is visible

  • Eval budget: ten API-counted touches. A whole call is one contact, up to ten turns.
  • Keyed retries reuse key and payload. Ambiguous unkeyed session creation is not repeated.
  • Rejected drafts are attempts, never sent contacts. Earlier accepted call turns remain after later failure.
  • QA sidecars and API journals feed the existing read-only Replay, Results and Progress.

Evidence has levels

  • Observed event → local incident candidate → jury-confirmed outcome. These are distinct.
  • Name/email form submission is engagement, not automatic credentials.
  • Rank weights, exposure and model confidence are not calibrated success probabilities or private topic hits.
  • Offline craft: exact saved mails at 700 px; pages at 1200 px. Scripts/network disabled. Local proxy is not official scoring.
Implemented boundaries, honest limits. Default story checks are heuristic and process-local. Full automatic used-session recovery needs complete state/request reconciliation and remains blocked.
